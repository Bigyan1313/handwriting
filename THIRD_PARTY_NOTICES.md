# Third-party assets

The root MIT license covers original project code and documentation. Bundled
third-party assets retain their own licenses and copyright notices:

- Handwriting fonts in `fonts/`: SIL Open Font License 1.1. See `fonts/OFL.txt`
  for the license and copyright notices extracted from the supplied fonts.
- KaTeX JavaScript and CSS in `assets/katex/`: MIT; see `assets/katex/LICENSE`.
- KaTeX fonts in `assets/katex/fonts/`: SIL Open Font License 1.1;
  see `assets/katex/fonts/OFL.txt`.

Personal handwriting samples and generated custom fonts are excluded from Git
by default. Contributors must have permission to share any new assets and
include their license notices.
